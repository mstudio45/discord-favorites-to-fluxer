# Discord to Fluxer GIFs

Inspired and certain parts of the code (api/discord.py, api/fluxer.py) are from [Jord38's fluxer-gif-migrator](https://github.com/Jord38/fluxer-gif-migrator). Follow the tutorial on his repository. <br />
This thing is badly coded and just put together to work. Don't expect much from it. <br />
Also, don't expect updates to this. I made this for fun when I was checking out Fluxer. <br />

## Info
Rename these files from that tutorial to these:
> data.json -> discord_data.json <br />
> config.json -> fluxer_data.json

## Supported URLs
- tenor.com
- giphy.com
- imgur.com
- any direct gif, webp, avif, mp4, png link (fluxer might fail fetching the metadata)
